# Md. Arif Islam Limon — Simple Portfolio

A minimal, responsive dark portfolio website for Business Analyst / Data Analyst opportunities.

## Preview
Open `index.html` in a browser. No build tools are needed.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your email address.
2. Review the education and experience text.
3. The project cards are explicitly labelled as planned ideas, not completed projects.

## Replace files on GitHub
1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload the new `index.html` and `README.md` from this folder.
4. Commit the changes. If GitHub warns that `README.md` already exists, make sure you upload/replace the existing file rather than creating a second copy.
5. If GitHub Pages is already enabled, it will redeploy automatically after the commit.
